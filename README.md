# جدول يومي - Jadwal Yawmi

> منظّم المهام والروتين اليومي — نظّم وقتك وأنجز مهامك بكفاءة

تطبيق ويب إداري للمهام والروتين اليومي مبني بتقنيات حديثة، مع دعم كامل للعربية وواجهة جميلة بطابع ترابي دافئ.

## ✨ المميزات

- 📋 **إدارة المهام** — إنشاء وتعديل وحذف المهام مع تصنيفات وأولويات
- 📅 **التقويم** — تتبع الأحداث والمناسبات مع تقويم تفاعلي
- 📿 **المركز الإسلامي** — أذكار الصباح والمساء، القرآن الكريم، والسنن النبوية
- 🔥 **تتبع العادات** — بناء عادات حسنة وترك السيئة مع تتبع السلاسل
- 🔔 **تنبيهات ذكية** — إشعارات للمهام المهمة في الوقت المناسب
- 🔐 **نظام مصادقة** — تسجيل حساب ودخول مع ملف شخصي
- 👤 **وضع الضيوف** — تصفح التطبيق بدون إنشاء حساب
- 🌙 **الوضع الداكن** — دعم كامل للوضع الداكن والفاتح
- 📱 **متجاوب** — يعمل على جميع الأجهزة (موبايل، تابلت، كمبيوتر)
- 🔒 **خصوصية تامة** — البيانات محفوظة على الجهاز فقط (IndexedDB)
- 🌐 **PWA** — يمكن تثبيته كتطبيق أصلي

## 🛠️ التقنيات

- **React 18** + **TypeScript**
- **Vite** — بناء سريع
- **Tailwind CSS** — تصميم مخصص بطابع ترابي
- **Zustand** — إدارة الحالة
- **Dexie** — قاعدة بيانات IndexedDB
- **React Router** — التنقل
- **Lucide React** — الأيقونات

## 🚀 التشغيل المحلي

### المتطلبات
- Node.js 18+
- npm أو yarn أو pnpm

### التثبيت

```bash
# استنساخ المستودع
git clone https://github.com/your-username/jadwal-yawmi.git
cd jadwal-yawmi

# تثبيت الاعتماديات
npm install

# تشغيل خادم التطوير
npm run dev
```

سيكون التطبيق متاحاً على `http://localhost:3005`

### البناء للإنتاج

```bash
npm run build
npm run preview
```
